    Private repo or rate-limited? Add an access token

    Tokens are stored per host in this browser's localStorage and sent only to that host's API — never to the server this page is hosted on. For GitLab create a personal access token with the read_api scope; for GitHub a classic token with no scopes is enough to lift the 60-calls-per-hour anonymous limit to 5,000.

    Offline mode — paste a git log instead
